# رؤى للرعاية الصحية المنزلية — RU-MD Home Healthcare

موقع ثنائي اللغة (عربي/إنجليزي) مع لوحة تحكم كاملة، مبني بنفس تقنيات **PlayTix 2.0**:
React 18 + Vite للواجهة، Express (Node.js) لواجهة REST، وقاعدة بيانات MySQL.

A bilingual (Arabic/English, RTL/LTR) website with a full admin dashboard, rebuilt
from the original WordPress site on the **PlayTix 2.0 stack**: React 18 + Vite front-end,
an Express (Node.js) REST API, and a MySQL database.

---

## ✨ المزايا / Features

- **واجهة عامة عصرية**: الرئيسية، من نحن، الخدمات (14 خدمة طبية)، صفحة الخدمة، تواصل معنا.
- **ثنائية اللغة بالكامل** مع تبديل فوري بين العربية (RTL) والإنجليزية (LTR) — وحدة ترجمة مركزية `src/translations.js`.
- **لوحة تحكم** (`/admin`) محمية بتسجيل دخول (bcrypt + JWT):
  - لوحة إحصائيات.
  - إدارة الخدمات (إضافة/تعديل/حذف) بمحرر ثنائي اللغة.
  - إدارة الصفحات والمحتوى (تحرير نصوص الرئيسية و«من نحن»).
  - صندوق رسائل التواصل/طلبات الخدمة مع الرد عبر واتساب.
  - إعدادات الموقع (الهاتف، العنوان، أوقات العمل، السوشيال…).
- **فرض الأرقام اللاتينية** على حقول الإدخال (نفس سلوك PlayTix).
- نظام **هجرات (migrations)** + **حذف منطقي (soft delete)** + **سجل تدقيق (audit log)**.
- **الطب الاتصالي (Telemedicine)**: مكالمات فيديو أو صوت داخل الموقع (Jitsi) — حجز ذاتي من مواعيد الأطباء
  المتاحة أو جدولة من الإدارة، حساب مستقل لكل طبيب، ملخص طبي بعد الاستشارة، وإشعارات للمريض والطبيب والإدارة.

## 🚀 التشغيل محليًا مع XAMPP / Local setup with XAMPP

### 1. المتطلبات
- Node.js 18+ (مثبت لديك 22 ✓)
- MySQL — عبر **XAMPP** (شغّل MySQL من لوحة تحكم XAMPP).

### 2. إعداد قاعدة البيانات والخادم
```bash
cd server
copy .env.example .env        # ثم عدّل القيم إذا لزم (Windows)
# على ماك/لينكس: cp .env.example .env

npm install                   # تثبيت تبعيات الخادم
npm run setup                 # ينشئ القاعدة + الجداول + يعبّئ المحتوى وحساب المدير
npm start                     # يشغّل الـ API على http://localhost:4000
```

> إعدادات XAMPP الافتراضية تعمل مباشرة: `DB_USER=root` وكلمة مرور فارغة.
> سيُنشئ السكربت قاعدة باسم `ruaa_healthcare` تلقائيًا (ترميز utf8mb4).

### 3. تشغيل الواجهة (في نافذة طرفية ثانية)
```bash
# من جذر المشروع
npm install
npm run dev                   # http://localhost:5173
```

الواجهة تمرّر طلبات `/api` تلقائيًا إلى الخادم على المنفذ 4000.

### 4. الدخول للوحة التحكم
افتح **http://localhost:5173/admin**

```
البريد:    admin@rumd.me
كلمة المرور: Admin@12345
```
> غيّرهما من ملف `server/.env` قبل أول تشغيل (`ADMIN_EMAIL` / `ADMIN_PASSWORD`).

## 📦 النشر للإنتاج / Production build

```bash
npm run build                 # ينتج مجلد dist/
```
الخادم (Express) يقدّم مجلد `dist/` تلقائيًا، فيكفي في الإنتاج:
```bash
cd server && npm start        # يقدّم الـ API + الموقع من نفس المنفذ
```
على **Hostinger**: ارفع المشروع، شغّل `npm run build` ثم `node server/index.js`،
واضبط متغيرات البيئة وقاعدة MySQL من لوحة الاستضافة (راجع `server/.htaccess.example`).

## 👩‍⚕️ الكادر الطبي الموحّد / Staff directory

صفحة **لوحة التحكم → الكادر الطبي** (`/admin/staff`) هي القائمة الوحيدة لكل من يعمل مع رؤى (طبيب، ممرض/ة، أخصائي…)
موظفًا كان أو **زائرًا/متعاقدًا** (بيانات الجهة والترخيص ومدة التعاقد). من بطاقة كل فرد تُمنح الصلاحيات:
- **الزيارات المنزلية**: يظهر اسمه في جدولة الزيارة بحسب التخصصات المحددة (بدل قائمة الأسماء القديمة في الإعدادات).
- **الطب الاتصالي**: إنشاء حساب دخول (`/login`) لبوابة الممارس مع مدة الاستشارة وأوقات التوفر.
- **لوحة التحكم** (لمدير النظام): ربط بمستخدم موجود أو إنشاء مستخدم جديد بصلاحيات عرض أساسية.

عند أول تشغيل بعد الهجرة `021_staff_directory.sql` يستورد الخادم تلقائيًا أسماء الكادر من الإعدادات
وحسابات الطب الاتصالي الموجودة إلى هذه القائمة (ويربط مستخدمي لوحة التحكم الذين يطابق بريدهم).

## 🩺 الطب الاتصالي / Telemedicine

| الجهة | المسار | الوظيفة |
|---|---|---|
| الزائر | `/telemedicine` | صفحة تعريفية + دعوة للتسجيل |
| المريض | `/portal` → قسم «الاستشارات الطبية عن بُعد» | حجز (فيديو/صوت، طبيب، يوم، وقت) — أو ترك الجدولة للإدارة — ثم زر **دخول الغرفة** قبل الموعد بـ 15 دقيقة |
| الطبيب | `/login` بحساب دوره `doctor` → `/portal` | استشارات اليوم/القادمة، الانضمام للغرفة، كتابة التشخيص والوصفة، أوقات التوفر الأسبوعية وأيام الإجازة |
| الإدارة | `/admin/telemed` | إدارة الأطباء (حساب + ملف + أوقات)، جدولة/تعيين الاستشارات، الحالة، المراسلات، الانضمام للغرفة |

- التشغيل: `npm run migrate` (يطبّق `019`–`021`) ثم امنح الصلاحية لأول ممارس من **لوحة التحكم → الكادر الطبي** (أو تبويب «الممارسون الصحيون» في صفحة الطب الاتصالي).
- الإعدادات (لوحة التحكم → الإعدادات): `telemed_enabled`، `telemed_price`، `telemed_slot_minutes`، `jitsi_domain`.
- صلاحية الصفحة لمستخدمي لوحة التحكم: مفتاح `telemed` (عرض/إضافة/تعديل/حذف).
- **مشغّل المكالمات**: افتراضيًا `meet.jit.si` العام — يتطلب أن يسجّل الطبيب دخوله كمشرف (Google/GitHub) عند فتح الغرفة.
  للتخلص من هذه الخطوة: فعّل **8x8 JaaS** (خطة مجانية) بوضع `JAAS_APP_ID` و`JAAS_KEY_ID` و`JAAS_PRIVATE_KEY` في `server/.env`
  (يولّد الخادم توكن موقّعًا: الطبيب/الإدارة مشرف، المريض ضيف)، أو استخدم خادم Jitsi خاص عبر `jitsi_domain`.
- الأوقات تُخزَّن كوقت محلي (`TELEMED_TZ=Asia/Riyadh`) وتُقطَّع تلقائيًا إلى مواعيد بحسب مدة استشارة الطبيب.
